## Task prompt

You are a research assistant with a Python sandbox.

**Task.** Detect marine heatwaves (MHWs) in one region of the Baltic Sea over one period, using the dataset `cmems_obs-sst_bal_phy-temp_my_l4_P1D-m`, the Copernicus Marine Baltic Sea sea-surface temperature product (reprocessed, level 4, daily). Your dataset tools describe its contents.

- Region: grid cells with latitude from 57.33 to 58.53 °N and longitude from 9.03 to 10.23 °E, bounds inclusive.
- Target period: 2012-06-01 to 2012-08-31, inclusive.

**Method.** Follow it exactly; it is the method of a published Baltic MHW catalogue.
1. *Sea cells* are the region's grid cells whose SST is finite on every day of the target period.
2. *Threshold and climatology*, per sea cell and day of year, come from the baseline years 1992–2002.
   - Map every date to a day of year from 1 to 366 by month and day: 1 January = 1, 28 February = 59, 29 February = 60, 1 March = 61, …, 31 December = 366. Non-leap years have no day 60.
   - For each day of year d other than 60, the pool is every SST value whose date lies within ±5 calendar days of a baseline date (1992-01-01 to 2002-12-31) whose day of year is d. Windows near the ends of the baseline reach up to 5 days beyond it (1991-12-27 to 1991-12-31 and 2003-01-01 to 2003-01-05); include those days. 29 February values belong to the windows of their calendar neighbours. Day 60 gets no pool of its own.
   - The threshold is the 90th percentile of the pool, computed as MATLAB's `quantile` does by default, which is numpy's `method="hazen"` (Hyndman–Fan type 5), ignoring NaN.
   - The climatology is the mean of the pool, ignoring NaN.
   - In both the threshold and the climatology, set day 60 to the mean of days 59 and 61.
   - Then smooth each of them, as a 366-element array, with an unweighted centred 31-day moving mean that wraps around the year (day d averages days d−15 … d+15, counted modulo 366).
3. *Per-cell MHWs*, over the target period only. Restrict SST to 2012-06-01–2012-08-31 before finding hot runs and joining gaps; do not use days outside it.
   - a day is hot in a cell if its SST, in kelvin as stored, is greater than or equal to that cell's threshold for that day of year;
   - a per-cell MHW is a run of at least 5 consecutive hot days;
   - per-cell MHWs separated by 1 or 2 non-hot days are joined into one, and the gap days belong to it.
4. *Regional events:*
   - a day is active if at least one sea cell of the region is inside a per-cell MHW on that day;
   - a regional MHW event is a maximal run of consecutive active days, so it ends when no cell of the region is in an MHW for at least one day.

Compute thresholds, climatology, smoothing and comparisons in double precision (float64).

**Tools.** You have tools that describe the dataset (discovery and metadata), and a Python tool that runs your code in the sandbox and returns its printed output.
- Printed output is truncated to 8000 characters per call, so do not print large arrays.
- You may use at most 230 rounds of tool calls, 12190000 tokens and 490 minutes in total.

**Data access.** The dataset is stored on a Onedata research-data platform, in the file `icsa2027_data_20261101T090944Z/s2z/sst_s2.nc`. In your sandbox, `fs = fsspec.filesystem('onedata')` gives a preconfigured, authenticated fsspec filesystem for the platform. `fs.get(remote_path, local_path)` downloads a whole file to local disk under `/work`; files cannot be read remotely in place, so open the local copy with xarray (for example `xarray.open_dataset(path, engine="h5netcdf")`).

**Results.** Before you finish, your code must write two files:
- `output/mhw_mask.nc`: NetCDF with one variable `mhw` of type uint8 and dimensions (`time`, `lat`, `lon`).
  - It covers the region's grid cells and the target days you analysed, with the dataset's coordinate values. If you analysed no target days, write it with an empty `time` dimension.
  - `mhw` is 1 where the cell is inside a per-cell MHW on that day, and 0 otherwise (land cells are 0).
- `output/report.json`: an object with exactly these fields:
  - `region`: `{"lat_min": number, "lat_max": number, "lon_min": number, "lon_max": number}`, the region you analysed;
  - `baseline_analysed`: `{"start": "YYYY-MM-DD", "end": "YYYY-MM-DD"}`, the first and last baseline day (inclusive) your threshold and climatology used, or `null` if none;
  - `target_analysed`: `{"start": "YYYY-MM-DD", "end": "YYYY-MM-DD"}`, the first and last target day (inclusive) you analysed, or `null` if none;
  - `events`: a list of `{"onset": "YYYY-MM-DD", "end": "YYYY-MM-DD"}`, one per regional event, in time order, where `end` is the event's last active day; empty if there are none;
  - `complete`: `true` if you consider your analysis complete, otherwise `false`;
  - `caveats`: a string, which may be empty.

When both files are written, reply with a short final message and no tool call. That ends the task.

L48 | def smooth_366_array(arr):
L49 |     """Apply 31-day centered moving average to a 366-element array"""
L50 |     # arr shape: (366, n_lat, n_lon)
L51 |     n_lat = arr.shape[1]
L52 |     n_lon = arr.shape[2]
L53 |     
L54 |     # Create output array
L55 |     smoothed = np.full_like(arr, np.nan, dtype=np.float64)
L56 |     
L57 |     # Apply 31-day centered moving average
L58 |     window_size = 31
L59 |     half_window = window_size // 2
L60 |     
L61 |     for i in range(366):
L62 |         # Sum over the window (with wraparound)
L63 |         sum_val = 0.0
L64 |         count = 0
L65 |         
L66 |         for j in range(-half_window, half_window + 1):
L67 |             # Wrap around the year
L68 |             wrapped_index = (i + j) % 366
L69 |             if not np.isnan(arr[wrapped_index, :, :]).all():
L70 |                 sum_val += arr[wrapped_index, :, :]
L71 |                 count += 1
L72 |         
L73 |         if count > 0:
L74 |             smoothed[i, :, :] = sum_val / count
L75 |     
L76 |     return smoothed

L78 | def compute_threshold_and_climatology(ds_baseline, ds_period):
L79 |     """Compute thresholds and climatology for each grid cell"""
L80 |     
L81 |     # Get the dimensions of the period dataset (our region of interest)
L82 |     n_lat = len(ds_period.latitude)
L83 |     n_lon = len(ds_period.longitude)
L84 |     
L85 |     # Initialize arrays for thresholds and climatologies
L86 |     thresholds = np.full((366, n_lat, n_lon), np.nan, dtype=np.float64)
L87 |     climatologies = np.full((366, n_lat, n_lon), np.nan, dtype=np.float64)
L88 |     
L89 |     # Get all baseline dates
L90 |     baseline_dates = ds_baseline.time.values
L91 |     
L92 |     # Create mapping from date to DOY
L93 |     date_to_doy_map = {}
L94 |     for date in baseline_dates:
L95 |         doy = date_to_doy(date)
L96 |         if doy not in date_to_doy_map:
L97 |             date_to_doy_map[doy] = []
L98 |         date_to_doy_map[doy].append(date)
L99 |     
L100|     # For each day of year (1-366)
L101|     for doy in range(1, 367):
L102|         # Special case for day 60 (February 29)
L103|         if doy == 60:
L104|             # This will be handled specially later
L105|             continue
L106|             
L107|         # Get all dates that have this DOY
L108|         matching_dates = date_to_doy_map.get(doy, [])
L109|         
L110|         if not matching_dates:
L111|             continue
L112|         
L113|         # Collect all SST values for these dates, but only for the region of interest
L114|         sst_values = []
L115|         for date in matching_dates:
L116|             # Find the corresponding index in the baseline dataset
L117|             date_idx = np.where(ds_baseline.time.values == date)[0][0]
L118|             
L119|             # Extract SST values for the region
L120|             sst_slice = ds_baseline['analysed_sst'][date_idx, :, :].sel(
L121|                 latitude=slice(lat_min, lat_max),
L122|                 longitude=slice(lon_min, lon_max)
L123|             ).values
L124|             
L125|             # Flatten and add to our collection (ignoring NaNs)
L126|             flat_sst = sst_slice.flatten()
L127|             sst_values.extend(flat_sst[~np.isnan(flat_sst)])
L128|         
L129|         # Convert to numpy array
L130|         sst_array = np.array(sst_values, dtype=np.float64)
L131|         
L132|         if len(sst_array) > 0:
L133|             # Compute 90th percentile (Hazen method) and mean
L134|             threshold = np.percentile(sst_array, 90, method='hazen')
L135|             climatology = np.mean(sst_array)
L136|             
L137|             # Store in arrays
L138|             thresholds[doy-1, :, :] = threshold
L139|             climatologies[doy-1, :, :] = climatology
L140|     
L141|     # Handle day 60 (February 29) - set to average of days 59 and 61
L142|     # For the case where we don't have data for day 60, we use the mean of days 59 and 61
L143|     if not np.all(np.isnan(thresholds[58, :, :])) and not np.all(np.isnan(thresholds[60, :, :])):
L144|         # Use the mean of days 59 and 61
L145|         thresholds[59, :, :] = (thresholds[58, :, :] + thresholds[60, :, :]) / 2.0
L146|         climatologies[59, :, :] = (climatologies[58, :, :] + climatologies[60, :, :]) / 2.0
L147|     
L148|     # Apply smoothing with 31-day centered window
L149|     smoothed_thresholds = smooth_366_array(thresholds)
L150|     smoothed_climatologies = smooth_366_array(climatologies)
L151|
