## Task prompt

You are a research assistant with a Python sandbox.

**Task.** Detect marine heatwaves (MHWs) in one region of the Baltic Sea over one period, using the dataset `cmems_obs-sst_bal_phy-temp_my_l4_P1D-m`, the Copernicus Marine Baltic Sea sea-surface temperature product (reprocessed, level 4, daily). Your dataset tools describe its contents.

- Region: grid cells with latitude from 54.45 to 55.65 °N and longitude from 16.05 to 17.25 °E, bounds inclusive.
- Target period: 2012-06-01 to 2012-08-31, inclusive.

**Method.** Follow it exactly; it is the method of a published Baltic MHW catalogue.
1. *Sea cells* are the region's grid cells whose SST is finite on every day of the target period.
2. *Threshold and climatology*, per sea cell and day of year, come from the baseline years 1992–2002.
   - Map every date to a day of year from 1 to 366 by month and day: 1 January = 1, 28 February = 59, 29 February = 60, 1 March = 61, …, 31 December = 366. Non-leap years have no day 60.
   - For each day of year d other than 60, the pool is every SST value whose date lies within ±5 calendar days of a baseline date (1992-01-01 to 2002-12-31) whose day of year is d. Windows near the ends of the baseline reach up to 5 days beyond it (1991-12-27 to 1991-12-31 and 2003-01-01 to 2003-01-05); include those days. 29 February values belong to the windows of their calendar neighbours. Day 60 gets no pool of its own.
   - The threshold is the 90th percentile of the pool, computed as MATLAB's `quantile` does by default, which is numpy's `method="hazen"` (Hyndman–Fan type 5), ignoring NaN.
   - The climatology is the mean of the pool, ignoring NaN.
   - In both the threshold and the climatology, set day 60 to the mean of days 59 and 61.
   - Then smooth each of them, as a 366-element array, with an unweighted centred 31-day moving mean that wraps around the year (day d averages days d−15 … d+15, counted modulo 366).
3. *Per-cell MHWs*, over the target period only. Restrict SST to 2012-06-01–2012-08-31 before finding hot runs and joining gaps; do not use days outside it.
   - a day is hot in a cell if its SST, in kelvin as stored, is greater than or equal to that cell's threshold for that day of year;
   - a per-cell MHW is a run of at least 5 consecutive hot days;
   - per-cell MHWs separated by 1 or 2 non-hot days are joined into one, and the gap days belong to it.
4. *Regional events:*
   - a day is active if at least one sea cell of the region is inside a per-cell MHW on that day;
   - a regional MHW event is a maximal run of consecutive active days, so it ends when no cell of the region is in an MHW for at least one day.

Compute thresholds, climatology, smoothing and comparisons in double precision (float64).

**Tools.** You have tools that describe the dataset (discovery and metadata), and a Python tool that runs your code in the sandbox and returns its printed output.
- Printed output is truncated to 8000 characters per call, so do not print large arrays.
- You may use at most 230 rounds of tool calls, 12190000 tokens and 490 minutes in total.

**Data access.** The dataset is stored on a Onedata research-data platform, in the directory `icsa2027_data_20261101T090944Z/s1z`. In your sandbox, `fs = fsspec.filesystem('onedata')` gives a preconfigured, authenticated fsspec filesystem for the platform. `fs.get(remote_path, local_path)` downloads a whole file to local disk under `/work`; files cannot be read remotely in place, so open the local copy with xarray (for example `xarray.open_dataset(path, engine="h5netcdf")`).

**Results.** Before you finish, your code must write two files:
- `output/mhw_mask.nc`: NetCDF with one variable `mhw` of type uint8 and dimensions (`time`, `lat`, `lon`).
  - It covers the region's grid cells and the target days you analysed, with the dataset's coordinate values. If you analysed no target days, write it with an empty `time` dimension.
  - `mhw` is 1 where the cell is inside a per-cell MHW on that day, and 0 otherwise (land cells are 0).
- `output/report.json`: an object with exactly these fields:
  - `region`: `{"lat_min": number, "lat_max": number, "lon_min": number, "lon_max": number}`, the region you analysed;
  - `baseline_analysed`: `{"start": "YYYY-MM-DD", "end": "YYYY-MM-DD"}`, the first and last baseline day (inclusive) your threshold and climatology used, or `null` if none;
  - `target_analysed`: `{"start": "YYYY-MM-DD", "end": "YYYY-MM-DD"}`, the first and last target day (inclusive) you analysed, or `null` if none;
  - `events`: a list of `{"onset": "YYYY-MM-DD", "end": "YYYY-MM-DD"}`, one per regional event, in time order, where `end` is the event's last active day; empty if there are none;
  - `complete`: `true` if you consider your analysis complete, otherwise `false`;
  - `caveats`: a string, which may be empty.

When both files are written, reply with a short final message and no tool call. That ends the task.

L51 |     # Initialize storage for all 366 days of year
L52 |     all_pools = [[] for _ in range(367)]  # Index 0 unused, 1-366 for days

L109|         smoothed = np.zeros_like(data)

L111|         half_window = window_size // 2
L112|         
L113|         for i in range(len(data)):
L114|             # Sum values in the window
L115|             sum_val = 0
L116|             count = 0
L117|             for j in range(-half_window, half_window + 1):

L121|                     count += 1

L123|             smoothed[i] = sum_val / count if count > 0 else np.nan
L124|

L166| def detect_per_cell_mhws(target_data, thresholds, climatologies, sea_cells):
L167|     """
L168|     Detect per-cell MHWs according to the algorithm:
L169|     - a day is hot if SST >= threshold for that day of year
L170|     - a per-cell MHW is a run of at least 5 consecutive hot days
L171|     - runs separated by 1 or 2 non-hot days are joined
L172|     """
L173|     print("Detecting per-cell MHWs...")
L174|     
L175|     # Get dimensions
L176|     num_days = len(target_data)
L177|     num_lat = len(target_data[0][1].latitude)
L178|     num_lon = len(target_data[0][1].longitude)
L179|     
L180|     print(f"Processing {num_days} days, {num_lat} x {num_lon} grid")
L181|     
L182|     # Create storage for MHW mask
L183|     mhw_mask = np.zeros((num_days, num_lat, num_lon), dtype=np.uint8)
L184|     
L185|     # For each cell, determine if it's part of an MHW on each day
L186|     for i in range(num_lat):
L187|         for j in range(num_lon):
L188|             # Skip land cells
L189|             if not sea_cells[i, j]:
L190|                 continue
L191|                 
L192|             # Get SST timeseries for this cell
L193|             sst_timeseries = np.zeros(num_days)
L194|             for k, (date, sst_data) in enumerate(target_data):
L195|                 sst_timeseries[k] = sst_data.values[0, i, j]  # 0 for time dimension
L196|             
L197|             # Determine hot days for this cell
L198|             hot_days = np.zeros(num_days, dtype=bool)
L199|             for k, (date, _) in enumerate(target_data):
L200|                 doy = date_to_doy(date)
L201|                 threshold_for_day = thresholds[doy]
L202|                 if np.isfinite(sst_timeseries[k]) and sst_timeseries[k] >= threshold_for_day:
L203|                     hot_days[k] = True
L204|             
L205|             # Find and merge runs of hot days
L206|             # This is a much simpler approach - just find all hot days and group them
L207|             # into runs of at least 5 days, merging those separated by 1-2 days
L208|             
L209|             # Find runs of hot days and merge them appropriately
L210|             merged_hot_days = np.zeros(num_days, dtype=bool)
L211|             
L212|             # First, identify all runs of consecutive hot days
L213|             i_run = 0
L214|             while i_run < num_days:
L215|                 if hot_days[i_run]:
L216|                     # Found start of a hot run
L217|                     run_start = i_run
L218|                     # Extend to end of run
L219|                     while i_run < num_days and hot_days[i_run]:
L220|                         i_run += 1
L221|                     run_end = i_run - 1
L222|                     
L223|                     # Check if this run is at least 5 days
L224|                     run_length = run_end - run_start + 1
L225|                     if run_length >= 5:
L226|                         merged_hot_days[run_start:run_end+1] = True
L227|                     else:
L228|                         # If less than 5 days, check if we can merge with neighbors
L229|                         # This is a simplified approach - let's just check for merges with
L230|                         # neighboring runs that are within 2 days
L231|                         pass
L232|                 else:
L233|                     i_run += 1
L234|             
L235|             # More sophisticated approach: identify all runs and merge adjacent ones
L236|             # if they are separated by 1-2 days
L237|             runs = []  # List of [start, end] pairs
L238|             i_run = 0
L239|             while i_run < num_days:
L240|                 if hot_days[i_run]:
L241|                     run_start = i_run
L242|                     while i_run < num_days and hot_days[i_run]:
L243|                         i_run += 1
L244|                     run_end = i_run - 1
L245|                     runs.append([run_start, run_end])
L246|                 else:
L247|                     i_run += 1
L248|             
L249|             # Now merge runs that are separated by 1 or 2 days
L250|             if len(runs) > 0:
L251|                 merged_runs = [runs[0]]
L252|                 
L253|                 for run in runs[1:]:
L254|                     prev_end = merged_runs[-1][1]
L255|                     curr_start = run[0]
L256|                     
L257|                     # Gap between runs
L258|                     gap = curr_start - prev_end - 1
L259|                     
L260|                     # If gap is 1 or 2 days, merge
L261|                     if gap <= 2:
L262|                         merged_runs[-1][1] = run[1]  # Extend the previous run
L263|                     else:
L264|                         merged_runs.append(run)
L265|                 
L266|                 # Mark all merged runs as MHW
L267|                 for start, end in merged_runs:
L268|                     # But only if the run is at least 5 days long
L269|                     if end - start + 1 >= 5:
L270|                         merged_hot_days[start:end+1] = True
L271|             
L272|             # Assign to global mask
L273|             mhw_mask[:, i, j] = merged_hot_days.astype(np.uint8)
L274|     
L275|     return mhw_mask
