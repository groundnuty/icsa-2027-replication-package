## Task prompt

You are a research assistant with a Python sandbox.

**Task.** Detect marine heatwaves (MHWs) in one region of the Baltic Sea over one period, using the dataset `cmems_obs-sst_bal_phy-temp_my_l4_P1D-m`, the Copernicus Marine Baltic Sea sea-surface temperature product (reprocessed, level 4, daily). Your dataset tools describe its contents.

- Region: grid cells with latitude from 56.63 to 57.83 °N and longitude from 20.23 to 21.43 °E, bounds inclusive.
- Target period: 2010-06-01 to 2010-08-31, inclusive.

**Method.** Follow it exactly; it is the method of a published Baltic MHW catalogue.
1. *Sea cells* are the region's grid cells whose SST is finite on every day of the target period.
2. *Threshold and climatology*, per sea cell and day of year, come from the baseline years 1992–2002.
   - Map every date to a day of year from 1 to 366 by month and day: 1 January = 1, 28 February = 59, 29 February = 60, 1 March = 61, …, 31 December = 366. Non-leap years have no day 60.
   - For each day of year d other than 60, the pool is every SST value whose date lies within ±5 calendar days of a baseline date (1992-01-01 to 2002-12-31) whose day of year is d. Windows near the ends of the baseline reach up to 5 days beyond it (1991-12-27 to 1991-12-31 and 2003-01-01 to 2003-01-05); include those days. 29 February values belong to the windows of their calendar neighbours. Day 60 gets no pool of its own.
   - The threshold is the 90th percentile of the pool, computed as MATLAB's `quantile` does by default, which is numpy's `method="hazen"` (Hyndman–Fan type 5), ignoring NaN.
   - The climatology is the mean of the pool, ignoring NaN.
   - In both the threshold and the climatology, set day 60 to the mean of days 59 and 61.
   - Then smooth each of them, as a 366-element array, with an unweighted centred 31-day moving mean that wraps around the year (day d averages days d−15 … d+15, counted modulo 366).
3. *Per-cell MHWs*, over the target period only. Restrict SST to 2010-06-01–2010-08-31 before finding hot runs and joining gaps; do not use days outside it.
   - a day is hot in a cell if its SST, in kelvin as stored, is greater than or equal to that cell's threshold for that day of year;
   - a per-cell MHW is a run of at least 5 consecutive hot days;
   - per-cell MHWs separated by 1 or 2 non-hot days are joined into one, and the gap days belong to it.
4. *Regional events:*
   - a day is active if at least one sea cell of the region is inside a per-cell MHW on that day;
   - a regional MHW event is a maximal run of consecutive active days, so it ends when no cell of the region is in an MHW for at least one day.

Compute thresholds, climatology, smoothing and comparisons in double precision (float64).

**Tools.** You have tools that describe the dataset (discovery and metadata), and a Python tool that runs your code in the sandbox and returns its printed output.
- Printed output is truncated to 8000 characters per call, so do not print large arrays.
- You may use at most 230 rounds of tool calls, 12190000 tokens and 490 minutes in total.

**Data access.** The dataset is stored on a Onedata research-data platform, in the directory `icsa2027_data_20261101T090944Z/s1z`. In your sandbox, `fs = fsspec.filesystem('onedata')` gives a preconfigured, authenticated fsspec filesystem for the platform. `fs.open(path, "rb")` reads a file remotely over the platform's REST API; open the returned file object with xarray (for example `xarray.open_dataset(f, engine="h5netcdf")`).

**Results.** Before you finish, your code must write two files:
- `output/mhw_mask.nc`: NetCDF with one variable `mhw` of type uint8 and dimensions (`time`, `lat`, `lon`).
  - It covers the region's grid cells and the target days you analysed, with the dataset's coordinate values. If you analysed no target days, write it with an empty `time` dimension.
  - `mhw` is 1 where the cell is inside a per-cell MHW on that day, and 0 otherwise (land cells are 0).
- `output/report.json`: an object with exactly these fields:
  - `region`: `{"lat_min": number, "lat_max": number, "lon_min": number, "lon_max": number}`, the region you analysed;
  - `baseline_analysed`: `{"start": "YYYY-MM-DD", "end": "YYYY-MM-DD"}`, the first and last baseline day (inclusive) your threshold and climatology used, or `null` if none;
  - `target_analysed`: `{"start": "YYYY-MM-DD", "end": "YYYY-MM-DD"}`, the first and last target day (inclusive) you analysed, or `null` if none;
  - `events`: a list of `{"onset": "YYYY-MM-DD", "end": "YYYY-MM-DD"}`, one per regional event, in time order, where `end` is the event's last active day; empty if there are none;
  - `complete`: `true` if you consider your analysis complete, otherwise `false`;
  - `caveats`: a string, which may be empty.

When both files are written, reply with a short final message and no tool call. That ends the task.

L223| def smooth_with_moving_average(data, window_size=31):
L224|     """Smooth data with a centered moving average that wraps around"""
L225|     n = len(data)
L226|     smoothed = np.zeros(n, dtype=np.float64)
L227|     
L228|     half_window = window_size // 2
L229|     
L230|     for i in range(n):
L231|         # Calculate indices for the window
L232|         start_idx = (i - half_window) % n
L233|         end_idx = (i + half_window) % n
L234|         
L235|         if start_idx <= end_idx:
L236|             # Simple case - no wraparound
L237|             window_data = data[start_idx:end_idx+1]
L238|         else:
L239|             # Wraparound case
L240|             window_data = np.concatenate([data[start_idx:], data[:end_idx+1]])
L241|         
L242|         smoothed[i] = np.mean(window_data)
L243|     
L244|     return smoothed

L246| def detect_mhws(sst_array, thresholds, climatologies, target_dates, latitudes, longitudes):
L247|     """Detect MHWs in the target period"""
L248|     print("Detecting MHWs...")
L249|     
L250|     # Create result array for MHW mask
L251|     mhw_mask = np.zeros((len(target_dates), len(latitudes), len(longitudes)), dtype=np.uint8)
L252|     
L253|     # For each day, determine if it's hot based on threshold
L254|     for t, date in enumerate(target_dates):
L255|         doy = date_to_doy(date)
L256|         
L257|         # Get the threshold and climatology for this day of year
L258|         threshold = thresholds[doy-1]  # Convert to 0-based indexing
L259|         climatology = climatologies[doy-1]
L260|         
L261|         # Check if we have valid threshold data
L262|         if np.isnan(threshold):
L263|             continue
L264|             
L265|         # Compare SST to threshold
L266|         sst_day = sst_array[t]
L267|         hot_days = sst_day >= threshold
L268|         
L269|         # Apply the hot days mask to the result
L270|         mhw_mask[t] = hot_days.astype(np.uint8)
L271|     
L272|     # Now apply the MHW criteria: runs of at least 5 consecutive hot days
L273|     # Also join gaps of 1 or 2 days
L274|     print("Applying MHW criteria...")
L275|     
L276|     # For each cell, process the time series
L277|     for i_lat in range(len(latitudes)):
L278|         for j_lon in range(len(longitudes)):
L279|             # Extract time series for this cell
L280|             time_series = mhw_mask[:, i_lat, j_lon]
L281|             
L282|             # Find runs of hot days
L283|             # Use scipy to label connected components
L284|             from scipy.ndimage import label
L285|             
L286|             # Label connected hot days (1s)
L287|             labeled_array, num_features = label(time_series)
L288|             
L289|             # For each feature, check if it's a valid MHW (at least 5 days)
L290|             for feature_num in range(1, num_features + 1):
L291|                 feature_mask = labeled_array == feature_num
L292|                 feature_length = np.sum(feature_mask)
L293|                 
L294|                 # If less than 5 days, set to 0
L295|                 if feature_length < 5:
L296|                     time_series[feature_mask] = 0
L297|                 # Otherwise keep as 1 (already set)
L298|             
L299|             # Now we need to merge gaps of 1 or 2 days
L300|             # This requires checking for sequences of 0s between 1s that are <= 2 days long
L301|             merged_mask = time_series.copy()
L302|             
L303|             # Find segments of 1s
L304|             for i in range(len(time_series)):
L305|                 if time_series[i] == 1:
L306|                     # Look ahead to see if there are any gaps of 1 or 2 days
L307|                     # and if so, extend the MHW
L308|                     j = i + 1
L309|                     gap_count = 0
L310|                     while j < len(time_series) and time_series[j] == 0 and gap_count < 2:
L311|                         gap_count += 1
L312|                         j += 1
L313|                     
L314|                     # If we found a valid continuation (gap <= 2), mark the gap days as 1
L315|                     if j < len(time_series) and time_series[j] == 1 and gap_count <= 2:
L316|                         # Extend the MHW through the gap
L317|                         for k in range(i+1, j):
L318|                             merged_mask[k] = 1
L319|                             
L320|             # Update the result
L321|             mhw_mask[:, i_lat, j_lon] = merged_mask
L322|     
L323|     return mhw_mask
