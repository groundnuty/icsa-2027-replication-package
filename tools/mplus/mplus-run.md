## What it does
1. **Preflight** (`--run` refuses unless every check is PASS): no dispatcher process, or one paused by its quiet window (`quiet_window` meta opened, not released, no `QUIET_WINDOW_RELEASE` file) with 0 attempts running (a bare zero count between two dispatches is UNKNOWN, not a drain; main's store has no `quiet_window` key until 15:50Z 5 Nov); no other `icsa.*` process and no `icsa-sbx-` container on `.23`; a stamp under 10 min old with `site-g_solo`, `host8_idle`, `site-f_restart_ok` all true (neither site-g nor `.8` can be read from `.23`; `site-g-solo-check.sh` reads this host's slot map); tree head, image tag, `onedata.pass` mode, `space.json` hash, site-g settings key readable, site-f's and site-g's internal addresses in `host_aliases.toml`; the child gets no `ICSA_TOKEN_SOURCE`, `ICSA_AUDIT_LOG` or slot keys; `memcap 1 true` runs.
2. **Barrier**: two pieces, S1 I48 then S2 I48 (each: cold on site-f, M+ required, M+ whole layout = 6 runs).
3. **Resume**: pieces in the seeded order, `--order literal` (S1 I48, I37, I01, I35, I06, then S2 I48, I01, I06, I35, I37) or `balanced` (3 of 5 per layout, then the rest).
4. **Tables**: `mplus-report --out OUT [--site-g-dir D] [--wan-dir D]` → `breakeven.json`; it runs after a halt too (it reads files only); late past `--tables-by` (08:30Z) is logged, not skipped. Only counts are logged from it.

## How it honours 07:30Z
A piece = one `mplus-measure --plan` call: layout L, a PREFIX n of L's seeded order (plan lists `order[:n]` for L, `[]` for the other layout). It must be a prefix: `measure` takes the cold/required alternation and the run tags from the instance's index in the list it gets, and a one-instance plan would break both and re-provision the 4 GB layout every call. Nothing smaller is safe (a call cannot be stopped; `require_ended` never cancels a transfer). Before each piece: never a start at or after 07:30Z, never with PAUSE or after a halt; with the barrier's measured figures, the largest n whose remaining work is projected to END by 07:30Z minus `--margin-s` (900), `--call-overhead-s` (900: listing, `transfer_health`, `wait_for_stop`) included; without figures (the barrier itself) the clock rule alone. The rest is logged `not_run`. A slow link can still overrun the piece in flight; nothing here can stop it.
Any non-zero exit, failed run record, `mplus_stopped` or `transfer_not_ended` halts all further measurement (site-f's replica may be changing); a step whose run directory already exists is refused, not retried.
